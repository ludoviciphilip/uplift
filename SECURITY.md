# Security Policy

Uplift modifies files in your Steam library (launch options, `Engine.ini`, gamescope/vkBasalt configs) and
downloads OptiScaler releases from GitHub, so we take security reports seriously.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities. Instead, use GitHub's private vulnerability
reporting for this repository:

👉 https://github.com/ludoviciphilip/uplift/security/advisories/new

Include as much detail as you can: affected version/commit, steps to reproduce, and the potential impact
(e.g. arbitrary file write, privilege escalation, unsafe download/verification).

We'll do our best to acknowledge reports promptly and keep you updated as we investigate and fix the issue.

## Supported versions

Uplift is pre-1.0 and does not yet maintain multiple release branches. Security fixes are applied to the
latest code on the default branch.
